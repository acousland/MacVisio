# Master inheritance — version 0.5

The importer now expands subshapes omitted by a master instance. Local `MasterShape` overrides take the corresponding place in the inherited group; additional local children remain independent. Nested groups and masters with multiple top-level shapes become editable native groups. The implementation follows [Microsoft's master-to-shape inheritance rules](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/74428617-9833-4d73-aa7f-f3a6f043a12d).

Inherited descendants receive page-unique model IDs. Each instance keeps its own master-to-page ID mapping for supported ShapeSheet references and master connection records. Inherited Shape Data, User cells and hyperlinks merge local row/cell overrides. Locally deleted rows and subshapes are omitted. Import uses cached numeric geometry; supported numeric formulas recalculate after edits.

An unchanged source page retains its exact XML bytes. Editing an unrelated shape leaves implicit master descendants absent from the page XML. Editing an inherited descendant writes a minimal `MasterShape` override and any required ancestor group shells. Deleting an inherited descendant writes a `Del` tombstone so it remains deleted on public-format reopen. Inherited property and hyperlink deletion similarly uses row tombstones. The [Shape schema](https://learn.microsoft.com/en-us/office/client-developer/visio/shape-element-shapes_type-complextypevisio-xml) and [row schema](https://learn.microsoft.com/en-us/office/client-developer/visio/row-element-shape-data-sectionvisio-xml) describe those attributes.

Source master definitions and their unknown content are preserved. Modern native metadata records inherited identity and is checked against all public parts. Older metadata that predates expansion is bypassed when a document contains masters, so it cannot conceal omitted public subshapes. The public drawing is reimported in that case.

The 19 regression tests remove private metadata when checking public save/reopen behavior and exercise text editing with native Undo/Redo. The bundled libvisio reader independently parses an edited descendant override and a binary export containing the expanded diagram. `Examples/Masters` contains the source VSDX, edited VSDX, experimental expanded VSD, native document, PNG/PDF exports and an application-generated native editor render. The independent reader's acceptance does not establish Microsoft Visio acceptance or complete rendering equivalence.

Full master editing, live instance updates, all ShapeSheet inheritance/expressions, geometry/control-handle semantics, resized-instance equivalence and complete grouped-connector transformations remain unfinished. Arbitrary inherited formulas retain cached geometry on import; the numeric evaluator covers a subset after editing. Unknown master solution behavior, automation and rich text are preserved where possible but not implemented. No Windows comparison or full installer-stencil suite was run.

Version 0.6 adds [grouped connector transforms](GROUPED-CONNECTORS.md). Ungrouping or reparenting a master member materializes its supported cached geometry, text, data, hyperlinks and images. Original master parts remain unchanged; surviving old inheritance slots receive deletion tombstones. Supported glue is rewritten to the actual materialized member. This does not implement full inherited expressions/actions: references to a removed master group may become unresolved and retain cached values.
