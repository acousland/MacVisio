# ShapeSheet formula and field reference (Visio 2019)

Reference evidence for WP-15-T02/T03 (functions, units, coercion, errors) and WP-16-T03/T04 (field
pictures, text measurement), recorded against Visio Professional 2019 16.0.10730 in the
`mondrian-win` reference guest (en-GB locale).

- `formula-cases.json`: the case set, generated by `scripts/reference-formula-cases.py`.
- `visio-results.json`: Visio's result for every case (ResultIU, ResultStrU, units code, cell error)
  and every field display, from `scripts/windows/Probe-VisioFormulas.ps1`.
- `context.vsdx`: the probe drawing Visio built and saved; MacVisio evaluates against this file, so
  both applications evaluate the same shapes.
- `macvisio-results.json`, `comparison.json`: MacVisio's results and the comparison
  (`scripts/compare-formula-probe.py`).
- `dispositions.json`: cases whose Visio result depends on the reference machine (time zone,
  installed fonts, in-memory floating point), East Asian calendar pictures (out of scope with
  Japanese input), document code MacVisio never runs, and open gaps.

Run everything again with `python3 scripts/run-formula-reference.py` (the guest must be running and
signed in). `VisioFormulaReferenceTests` replays the recorded Visio results offline on every test run.
