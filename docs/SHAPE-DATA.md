# Shape Data editing

MacVisio imports and exports public VSDX Shape Data rows. The editor offers fixed-list choices for Type 1, `TRUE`/`FALSE` choices for Type 3, and an editable list for Type 4. A fixed-list edit must match one of the semicolon-delimited `Format` entries; an unchanged legacy value outside that list is retained. Entering a new variable-list value appends it to the semicolon-delimited format. Boolean edits accept `TRUE`, `FALSE`, `1`, or `0`, while unchanged source encodings are preserved.

Type 2 edits accept finite numeric literals and the recognized Visio measurement forms supported by the ShapeSheet parser. Values keep the spelling the user entered, and the `Format` picture remains untouched. Untouched legacy values are retained even if they do not pass this validation. Visio's Type 2 can represent dimensions, scalars, angles, dates, times, and currency depending on its `Format`; this editor does not interpret those format pictures or retain a separate value-unit field.

Type 5 accepts ISO calendar dates (`YYYY-MM-DD`) and date-times with seconds, optional fractional seconds, and an optional time-zone offset. Type 6 accepts finite numeric elapsed-day values, and Type 7 accepts finite numeric currency amounts. These editors validate the entered value but leave its spelling and the row's `Format` picture intact; they do not render or interpret Visio date, duration, currency, locale, or picture formats. Untouched legacy values are preserved even when they fail the new-value validation. Blank values are allowed. Type 0 strings also pass through unchanged. Data-link refresh and external data behavior are not implemented.

Microsoft describes the type meanings and formatting pictures in the [Shape Data row](https://learn.microsoft.com/en-us/office/client-developer/visio/shape-data-row-shape-data-section), [Type cell](https://learn.microsoft.com/en-us/office/client-developer/visio/type-cell-shape-data-section), and [Format cell](https://learn.microsoft.com/en-us/office/client-developer/visio/format-cell-shape-data-section) references. MacVisio's accepted date syntax and validation rules are a bounded editing subset, not full Visio date and regional-format behavior.
