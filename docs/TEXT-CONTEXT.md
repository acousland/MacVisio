# Text and ShapeSheet context

Version 0.17 connects typed values and text functions to geometry, controls and native document editing. It does not establish complete ShapeSheet or Windows layout compatibility.

## Implemented behavior

- `STRSAME` now uses a case-sensitive default and treats its optional TRUE flag as ignore-case. The previous implementation inverted that flag. Microsoft's [STRSAME reference](https://learn.microsoft.com/en-us/office/client-developer/visio/strsame-function) supplies the behavior.
- `TheText` and `SHAPETEXT` resolve current and cross-shape text. Flags support discretionary-hyphen retention, omission of expanded field text, tab/newline/quote conversion and whitespace collapse. Tab expansion uses eight-column stops, and default discretionary-hyphen handling removes the marker; exact layout-dependent tab/hyphen behavior remains incomplete. See Microsoft's [SHAPETEXT reference](https://learn.microsoft.com/en-us/office/client-developer/visio/shapetext-function).
- `TEXTWIDTH`/`TEXTHEIGHT` use native attributed text, target-shape fonts, wrapping, margins and drawing scale. Width can be constrained; height uses the text-block width when no maximum is supplied. Supported cached paragraph spacing and indents affect native rendering and measurement. See the [width](https://learn.microsoft.com/en-us/office/client-developer/visio/textwidth-function), [height](https://learn.microsoft.com/en-us/office/client-developer/visio/textheight-function), [spacing](https://learn.microsoft.com/en-us/office/client-developer/visio/spline-cell-paragraph-section) and [paragraph-space](https://learn.microsoft.com/en-us/office/client-developer/visio/spbefore-cell-paragraph-section) references. Mac font substitution and native layout may differ from Visio; these measurements are not verified pixel equivalence.
- Text/Boolean/date/number dependencies resolve through top-level, User, Property, connection, Geometry and Control cells. Same-page Sheet IDs, ParentShape references and basic ThePage dimensions/scale are supported. Property type and STR/DATE caches retain their value types. Unsupported functions, cycles and limits produce issues while calculated geometry retains its cache where possible.
- Control behavior and Prompt expressions recalculate after supported text/property edits. Text-sensitive IF/IFERROR branches also work during SETATREF dragging. Text-transform dimensions, pins, local pins, angle, margins and vertical alignment recalculate into the native text block.
- Geometry and field calculations run to a bounded fixed point within a native document edit. Eight-pass nonconvergence is diagnosed rather than claimed to be a successful complete calculation. Undo/Redo restore the recorded diagram and its calculation messages exactly, without adding new derived cells during restoration.
- The native ShapeSheet grid edits supported transform/text cells and typed User/Property values, retaining units. New single-cell editing validates and recalculates transactionally. The grid still lacks complete section management and every cell type/function.
- Typed numeric functions pass full-precision numbers through expression trees instead of formatting them to twelve digits. Compatible dimensional MIN/MAX/SUM results retain units; incompatible length/angle operations reject the expression. Geometry uses the existing scalar arithmetic convention. Complete dimensional algebra and implicit-unit display behavior remain unfinished.
- Implicit DL/DP/DT/DA/DE literals use their internal numeric values. `REF()` produces a diagnosed #REF! error and can be caught by IFERROR; it is not treated as an unknown function. See Microsoft's [unit reference](https://learn.microsoft.com/en-us/office/vba/visio/concepts/about-units-of-measure-visio) and [REF reference](https://learn.microsoft.com/en-us/office/client-developer/visio/ref-function).

## Evidence and remaining work

Eighteen new regressions cover the case flag, text flags, live controls/tooltips, typed property-driven geometry, cross-shape text/fonts, wrapping/margins/scale, automatic dimensions/text transforms, typed control redirection, public XML preservation, precision/dimensional aggregates, cached failures, native editing/Undo/Redo, field/control coordination, typed cell editing/date caches, paragraph spacing and implicit units/reference errors.

Actual installer tests use `ANALYTICS_M.VSSX` to change a text-sensitive handle from hidden to visible and `BLDCOR_M.VSSX` to match a staircase's DL-based control coordinate. The CLI `--inspect-calculation input report.json` now audits formulas in shape, geometry, connection, control, User, and Property cells, reporting function usage and failure causes against imported page snapshots. See [ShapeSheet coverage audit](SHAPESHEET-AUDIT.md). This is not an open/edit/save workflow test or Windows comparison.

`Examples/TextContext` contains before/after VSDX, experimental VSD, native JSON, PNG/PDF exports and an editor hierarchy render. Public VSDX retains the formulas. Experimental public VSD contains saved graphics/text rather than complete live expression semantics.

Outstanding requirements include every ShapeSheet function/section and dimensional type, indexed text references, live paragraph formula evaluation, tab stops, bullets, complete mixed-font layout, field-format/context coverage, exact Windows metrics, arbitrary shape-name references, control dynamics/gluing, master updates, automation/events and specialist solutions. Existing imported caches are not proof that those behaviors are implemented. Full parity remains unfinished.
