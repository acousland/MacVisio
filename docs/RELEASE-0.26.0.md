# MacVisio 0.26.0

MacVisio now looks and is laid out like Microsoft Visio 2019.

**Ribbon.** The ribbon has Visio's ten tabs, from File to Help. Each tab has Visio's groups and commands, in Visio's order and arrangement. The "Tell me what you want to do" box finds commands by name. The tabs, groups and commands were captured from Visio 2019 itself and are checked automatically.

- 52 of Visio's 137 ribbon commands work in this release.
- The rest are shown in their Visio positions but are unavailable; their tooltips say so. More will be enabled in future releases.

**File.** The File tab opens a Visio-style view with Info, New, Open, Save, Save As, Print, Share, Export, Close, Account and Options.

- Export formats (PDF, PNG, JPEG, TIFF, SVG, VSDX, VSD and templates) are under File > Export.
- The Dark, Light or System appearance is chosen in File > Account, as the Office theme is in Visio.

**Window.**

- The Format Shape pane is a task pane, as in Visio. It is hidden until you open it from Home > Shape Styles > Format Object or View > Task Panes, and MacVisio remembers your choice.
- The status bar shows the page number, the language and the selected shape's width, height and angle, with a zoom slider.
- The page tabs end with All, which lists every page, and +, which adds a page.
- View > Ruler shows or hides the rulers.

MacVisio keeps its own icons; Microsoft's icon artwork and branding are not used. ShapeSheet, geometry and shape operations are not on Visio's default ribbon, so they stay in the menu bar. Accessibility and Japanese input remain outside scope.

Apple Silicon and macOS 27.0.1 or later are required.
