# Native text fields

Version 0.11 models Field section rows, indexed `fld` insertion markers and their saved display text. Fields retain cached values, formulas, units, formatting and other row cells. Character/paragraph styling remains attached to each insertion. Unchanged VSDX packages retain source part bytes; supported edits update field caches without flattening the references.

## Editing and calculation

Shape > Insert Text Field offers page name/number/count, dimensions, current date, Shape Data and custom formulas. Insertion uses the current text selection or the end of a selected shape. Shape > Text Fields edits definitions and removes fields with Undo; removal keeps the current display as ordinary text. Supported formulas update after native edits. Unsupported calculations preserve saved display text and report an issue.

The field evaluator supports strings, booleans, numeric values, measured lengths/angles and dates. String literals, concatenation, conditional expressions, numeric functions and basic string functions are available. Page functions include PAGENAME, PAGENUMBER, PAGECOUNT and BKGPAGENAME; background pages are excluded from the foreground page count. References can resolve local Shape Data/User/geometry cells, Sheet IDs, ThePage dimensions and indexed Fields.Value cells. Master and clipboard references are scoped to the inserted instance.

`INDEX(index,list[,delimiter[,errorvalue]])` supports zero-based selection, the default semicolon delimiter, multi-character delimiters, and empty list entries caused by leading, trailing or repeated delimiters. It returns an empty string by default when out of range, or the evaluated errorvalue token when supplied. The index must be a finite whole-number literal; a negative whole number is out of range, while fractions and non-number index values are rejected. An explicitly empty delimiter is rejected. Very large list/delimiter searches and text inputs are bounded; string-to-number and other index coercion rules are not claimed as Visio-compatible.

Supported formatting includes general/fixed decimal numeric codes, unit labels, basic numeric pictures, common Gregorian date pictures and selected internal date codes. NOW, TODAY and DATE use the host's calendar/time context. Complete dimensional coercion, all date/calendar/locale semantics, complex units, currencies and every Visio format remain incomplete. This is not a complete ShapeSheet evaluator.

Shared background fields are calculated in a foreground render context without mutating their stored page. PNG/SVG/PDF composition and native background display can show different page names and numbers on each foreground page. The independent reader uses saved caches rather than all Visio formulas; its background output is not proof of dynamic Windows behavior.

The inline editor shades field spans and represents empty fields with a placeholder. Formatting and unchanged text preserve the reference. Replacing a field's displayed text converts the edited span to literal text. Source row definitions remain available unless explicitly removed. Native field insertion/edit methods and Undo are tested inside isolated AppKit instances; manual clicking and font/menu routing remain unverified.

## Both drawing formats

VSDX exports public Field rows and cached fld text. Old private metadata is bypassed if it would hide field references. Older native JSON does not reconstruct all missing field models automatically; reimport its public VSDX source when needed.

Experimental binary VSD now uses UTF-16 field placeholder characters, public name lists, ordered field lists and text field records containing cached strings. These records are parsed without MacVisio's private stream. Full binary field expressions, original-object preservation and foreground-dependent binary background fields remain incomplete. Saved caches and native metadata do not establish complete Windows compatibility.

## Verification

The suite passes 201 tests. Fifteen additional tests cover public import, sparse references, source-byte preservation, page/data/resize updates, source and fresh exports, unsupported-cache fallback, repeated adjacent fields, formatting/text edits, empty placeholders, caret insertion/Undo, typed strings/measures/date formatting, foreground numbering, shared backgrounds without mutation, metadata upgrades, actual installer dimension fields, public binary records without private metadata and mixed explicit/allocated shape IDs. Some tests cover several related conditions.

The real MWFC_MEDIA_R2L template's point-valued width field updates to `200 pt.` after resizing. `Examples/Fields/release-review` supplies native/VSDX/VSD/VSTX and rendered artifacts with live status, drawing width and a shared page-information footer. Its native hierarchy render is [field-editor-preview.png](field-editor-preview.png), generated by the app and visually inspected.
