`InputContainerTrustTests` adds **6 passing tests** (`build/m2-container-trust.log`, 0.128 seconds). A raw stored-ZIP fixture writer deliberately retains duplicate/unsafe names, Unix symlink metadata, invalid checksums and over-budget declarations. A positive control first establishes that ordinary opaque bytes read successfully. CFB fixtures start from successfully decoded files, then alter FAT directory-chain links, directory siblings, mini-FAT links and declared stream sizes. No archive entries are extracted to disk by the reader.

Historical preparation command: `swift test --scratch-path build/m2-swift -j 2 --filter InputContainerTrustTests`. That focused run followed a test-only addition on the earlier 512-test preparation source. It strengthens rejection evidence without closing whole-process resource isolation, signed distribution or M2 acceptance. The later image/converter fixes and full regression supersede its earlier implementation gaps.
