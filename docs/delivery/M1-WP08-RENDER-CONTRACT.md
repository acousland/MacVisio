# M1 retained rendering contract

The document owns committed values; `RetainedRenderScene` owns a serial UI cache. Its `EvaluatedSceneSnapshot` contains immutable value pages, prepared routes and connection positions for one revision. Reusing UI cache objects never changes an older value snapshot. Jobs receive captured values or recorded PDF/SVG bytes, not mutable UI caches.

Foreground-specific background fields resolve during scene preparation. Paint and connector/shape hit testing read prepared scene values: they do not evaluate formulas, read files or mutate the document. Ordinary drag/resize uses view-owned geometry. Preview scenes clone committed evaluated ports/routes; a private formula-free routing value projects committed local port positions through the preview size/flip/rotation. Source formulas remain in the original preview/model and are evaluated at committed release. Background evaluated layers are reused. Control dragging moves the handle overlay; redirected formulas are evaluated on release. Save/autosave reads committed geometry throughout a gesture.

Both screen and publication drawing use the retained page renderer and layer color/visibility policy. Printability is explicit: screen-only layers remain visible in editing and are omitted from publication. Screen selection, handles, grid, rulers and shadows remain editing decorations. SVG uses the same evaluated values and layer policy through vector fragments.

Spatial queries reject unrelated nodes/edges before path or text preparation. Prepared node values are keyed by page/object identity and verified against the complete colored input plus paper scale. Their retention charge includes four times encoded source-object bytes plus path/text overhead, so opaque payloads and images are not hidden by a cheap key. Global node preparation retains at most 4,096 entries/32 MiB charged cost; labels retain at most 4,096 entries/32 MiB. Images retain at most 128 entries/64 MiB decoded pixel plus compressed-source cost. Oversize entries render without entering a cache. These are conservative retention costs, not exact allocator measurements.

Routes belong to the evaluated scene and include endpoint geometry, ports, obstacle, constraint and page inputs. Formatting-only edits reuse them. Endpoint/port edits invalidate incident routes. Obstacle insertion/move/delete conservatively invalidates automatic orthogonal routes: removing an obstacle can enable a shorter path outside the old route. That fallback is counted, rather than described as local. Explicit routes and unrelated straight routes retain their results. Route table bytes are reported separately from the bounded path/text caches; scene lifetime is bounded by UI/job ownership and input limits.

Painting can prepare a previously uncached visible node/label; this performs AppKit path/text preparation, never semantic calculation. Cold/warm preparation counts remain distinct. New scene/route preparation, broad-phase candidate visits, actual drawing and text measurements have separate counters. No claim is made that a warm render qualifies cold import or that formula-node counts include value-model diff scans.

`PreviewCalculationContractTests` adds twenty transformed port projections, twenty native event-handler drag/resize/cancel cycles with no parser/cell/calculation work, release/undo/native readback equivalence and sparse port/append-route reuse. `RetainedSceneTests` covers 5,000-shape small-region work, warm cache reuse, no parser entry during drawing/hit testing, route/obstacle/style invalidation, layer output policy and paper/view coordinate boundaries. `RetainedEditorUITests` covers persistent controls and per-page view state. Native routed event traces, final full suites and named-host performance samples remain required before acceptance.
