## Diagnostic identity, freshness and coverage

`DocumentDiagnostic.calculationFailure` is called inside the geometry and text-field evaluators while the exact page, node and attempted cell are still available. Identical messages on different shapes or cells remain distinct records. The geometry producer covers authored geometry/text/control/connection-point/user/property cells and geometry render/range failures. Aggregate rendering failures identify their known owning shape without inventing a particular cell. Text fields distinguish value evaluation from format evaluation; a later formatting failure identifies the field owner without falsely attributing it to a particular authored cell.

Failed evaluation retains the model's existing geometry or text and reports `cached`, not evaluated output. The document stamps accepted records with `diagnosticInputKey`, containing its lifecycle owner, exact committed state identity and revision. `CalculationJobs` retains M1's owner/snapshot/revision gate before any publication. Unchanged pages carry their exact structured baseline alongside existing issue strings. Undo restores the matching diagnostic maps and stamps the restored committed identity. A direct model assignment makes older records visibly `stale`; a subsequent accepted calculation refreshes the diagnostic baseline and its session before assigning current keys.

`currentDiagnostics` combines producer-supplied typed importer records, remaining anonymous importer warnings, accepted calculation records and supplemental records. Successful Visio/legacy reads adopt `VisioImportResult.diagnostics` and current document keys; native reads clear prior source events and re-establish current facts from any embedded archive through the root-owned `ImportedSourceDiagnostics.scan`. Background serialization runs that scanner against the exact captured saved snapshot with its returned archive and stores the result in the exact save artifact. Only successful source-compatible preservation rebases install those already-computed records, preserving newer live edits and semantic/runtime identity. A synchronous prepared-save fallback does no source scan on main; it retains prior source facts explicitly stale and adds an informational unavailable-coverage note until reopen. The fallback note is deduplicated. This bounded scan runs at read or on the serialization worker, never in main rebase, getters or paint paths. Previously typed messages are retired from anonymous display after source rebase while raw `importWarnings` remain unchanged; the retired set is bounded by that read's compatibility-warning array and resets on read. Successful reads reset old calculation/supplemental records, while a failed read does not erase the existing baseline. Typed import events remain source-import facts rather than a claim of reimport/evaluation after every edit. An anonymous warning is omitted from display only when a typed producer event has the identical message; this does not infer source identity from prose. `setSupplementalDiagnostics(_:inputKey:)` rejects another input or document's key. Supplemental records become stale after an unrelated committed edit until the responsible producer refreshes them. Legacy anonymous calculation prose, when no structured producer records are available, is explicitly document-scoped with unavailable evaluation status. Anonymous imported/calculation strings carry the current document key and `unavailable` display state, and never gain fabricated page/object/cell identities. Calculation display dedupes only exact producer-generated message strings, leaving any residual legacy notes explicitly document-scoped. Text/control/field producers supply the exact legacy wording at their actual catch sites rather than parsing anonymous prose. This does not claim a complete importer adapter, unique source identity for anonymous notes, all dependency semantics, or complete document diagnostic coverage.

`showDocumentIssues(_:)` presents one window owned by its document. Its observer filters by the exact document instance. Rows expose severity, origin and display state; selectable details expose the actual supplied source part, source ID and authored cell. `navigateDocumentDiagnostic(_:)` checks current record membership and target existence, switches the owning editor's page, selects the shape/connector, scrolls to retained bounds, and exposes the authored cell. A foreign document's record cannot navigate a matching UUID. The existing import-notes action opens this unified pane; root-owned menus can call the new action directly. Status counts material records; informational metadata stays available without raising that count. The pane explicitly states that supplied producer coverage is incomplete.

## Save-impact assessment and admission

`DocumentSaveImpact.assess` performs no file I/O and consumes values only. A `Baseline` captures the loaded source or exact successful save, rather than a selection, gesture overlay or a later live model. A failed write or Save a Copy does not replace this baseline. A successful real save installs the exact captured baseline and any matching rebased preservation artifact under M1's existing save identity checks.

Native model output retains the value model and preserved sources. Binary Visio output is classified as reconstruction unless the original legacy title/pages are unchanged and the writer can reuse its original bytes. For preserved OPC sources, the current bounded classifier covers digital-signature parts, known solution parts, edited foreign shapes, changed master hierarchy/cell overrides, and edited objects with current failed-cell records. Risks carry a feature, feature dimension, actual target and available source provenance. An unchanged affected object stays quiet during an unrelated edit. Restoring the source snapshot clears edit impact. Arbitrary harmless opaque parts do not trigger a modal warning. A changed page whose source XML cannot be classified is unresolved. Affected shapes/connectors with unknown direct feature elements or sections are also unresolved; untouched owners remain quiet. The recognized shape-child vocabulary is `Cell`, `Section`, `Text`, `Shapes`, `ForeignData`. Implemented section handlers recognize `Geometry`, `Character`, `Paragraph`, `User`, `Property`, `Hyperlink`, `Connection`, `Control`, `Controls`, and `Field`. `Actions` is recognized separately as unsupported behavior and receives its own explicit risk. Literal metadata stays quiet. Unknown formula calls, malformed formulas, or nonliteral formulas in an unclassified direct-cell host also remain unresolved. The bounded function-name vocabulary mirrors accepted dependency/evaluator adapters; name recognition does not certify arity, host semantics or reference parity, and real evaluator failures retain their own risk. This follows M0's explicit unknown remainders rather than treating its scoped inventory as exhaustive. This is not a general proof that every unknown solution, master, formula, embedding or source feature is safe.

Signatures are document-wide. Changed signed content needs review; a signed package with native metadata also needs review because the existing writer may rewrite that part even for semantically unchanged pages. Known solution data has unresolved behavior after edits. Foreign bytes may remain preserved while behavior changes; its risk is therefore labeled behavior rather than claiming byte loss. An ordinary declared Bitmap with one source relationship, recognized attributes/children, supported PNG/JPEG compression and actual complete in-memory PNG/JPEG image sources remains quiet during supported edits. ImageIO inspects the supplied byte source and bounded header dimensions without pixel decoding or file I/O. Malformed bytes, OLE/Object types and unknown foreign features remain under review; the bitmap exception does not suppress separate unknown-section/Actions risks. The policy does not infer unsupported feature identities by parsing diagnostic prose.

An affected object with an explicit imported binding but no matching local source element is unresolved, while a genuinely unbound native object stays quiet. This conservative rule also requires review for model-only inherited master descendants whose local source element is intentionally absent; this slice does not establish a narrower safe classification for that case. Per-object source inspection starts at the page's actual `Shapes` container, including its nested descendants.

The document assesses the exact captured snapshot before admitting serialization. Risky same-original explicit saves offer Cancel, Save a Copy and Save Native Copy. A chosen copy must use another canonical destination, including symlink resolution; it retains the original request's captured state rather than taking a later snapshot. Copies use Save To semantics, preserving the original URL and dirty state. Automatic same-original operations cannot accept a destructive conversion and fail closed. Without a window the explicit path also fails with recovery guidance. Closing while a policy choice is pending cancels that held request once; queued saves retain M1's bounded admission/drain behavior. `resolveSaveImpact` injects a concrete decision/destination for tests without a modal UI.

`DocumentWritePolicy.requireWritableOriginal` separately refuses a source with no POSIX write bits or `isWritable == false`. This prevents atomic replacement through a writable parent from bypassing a read-only source. Captured saves and non-admitted direct same-source writes use this policy; a separate Save As destination remains available. Its typed failure is `DocumentWritePolicy.Failure.readOnlySource`. M1's external source fingerprint checks, safe-write checks, failure baseline, saved/recovery identity, text-finalization continuation and asynchronous snapshot ownership remain authoritative.

## Shared editor protection hook

At the root agent's request, `modifySelection` uses the root-owned `NativeEditProtection` helper before applying ordinary property changes. Group geometry changes are prepared on a candidate page, then every changed descendant and represented group-owned connector lock is checked against the preceding page. A blocked member rejects that entire root transform, preserving the group/children/edges and supplying an explanation. An allowed group transform remains one committed undo action. Explicit lock toggles remain separate and permitted. This covers model-represented node protections and connector layer/group locks; it does not invent missing connector-specific source-cell protection metadata or qualify pointer/accessibility group-transform journeys.
