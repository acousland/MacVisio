# Connection points — version 0.7

The native model now retains named and indexed Connection rows, cached X/Y cells with formulas, direction vectors and inward/outward/both type. Coordinates use local inches measured from the shape's lower-left corner, following [Microsoft's connection-point reference](https://learn.microsoft.com/en-us/office/client-developer/visio/connection-points-row-connection-points-section). Named references such as `Connections.Input.X` and indexed aliases such as `Connections.X1` identify ports. `ToPart` uses 100 plus the zero-based row index, as described by [Microsoft](https://learn.microsoft.com/en-us/office/vba/api/visio.connect.topart).

The Connector tool draws port markers and snaps clicks to eligible inward/both ports. Shape → Connection Points opens a native grid for coordinates, formulas, names, indexes, directions and type. Rename updates attached wires. Deletion detaches a wire at its previous physical endpoint; Undo restores the point and glue. Group transforms, cached routes and copying retain port attachments. Formula-based points follow Width/Height, while literal coordinates retain their local distance. Supported numeric port expressions also participate in ShapeSheet dependencies.

VSDX import merges master rows and instance overrides. Public saves write port-specific `Connect` targets and endpoint references. Deleted inherited ports receive row tombstones. Named sparse/deleted slots retain their index through deleted placeholder rows. Supported edits preserve unknown cells in existing rows. An explicit local endpoint override suppresses inherited master glue, preventing detached wires from reattaching on reopen. Older native VSDX metadata is bypassed when it predates connection-point modeling and public sections contain ports.

Fifteen regression tests exercise public reopen without private metadata, native grid update methods and event-method snapping, dependency calculation, hierarchy, copy, deletion and inherited instance behavior. `Examples/Ports` contains native/VSDX/experimental-VSD files, a diagram PNG and an application-generated editor render. Independent binary parsing verifies cached graphics; checked native VSD metadata retains ports for reopening in MacVisio.

Public binary port/glue declarations are not yet complete. Direction/type alignment rules, extended A/B/C/D port behavior, all ShapeSheet coordinate transformations, constraint routing and Windows differential acceptance remain unfinished. Native archives created before this feature may lack port editing state until reimported from public VSDX. Limits include 1,000 ports per shape and named-row indexes below 1,000. Preservation of source data is not evidence that all inherited port behavior is implemented.
