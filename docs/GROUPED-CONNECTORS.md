# Grouped connectors — version 0.6

Connectors now carry a group parent alongside their page-coordinate cached routes. This matches Visio's [shape containment model](https://learn.microsoft.com/en-us/office/vba/api/visio.shape.parent). Public nested contents are exported in their parent's coordinate system; Microsoft's [SetCenter description](https://learn.microsoft.com/en-us/office/vba/api/visio.shape.setcenter) documents that coordinate convention.

Group moves, resizing, rotation and flips transform every cached point, including detached endpoints and routes inside nested groups. Attached automatic routes are captured before transformation so they rotate with the group. Internal connections join a newly created group; new native connections use the nearest common ancestor. Ungrouping reparents owned edges and keeps physical endpoints. Group deletion removes detached owned edges as well as attached edges, with native Undo restoration.

Copy/duplicate includes group-owned detached routes, remaps parents and preserves endpoint positions when referenced nodes are outside the copied fragment. Ancestor layer visibility, lock and print flags now apply to owned edges. Repeated drag events start from the original document snapshot, preventing cumulative resize scaling. Distribution also moves group contents and their routes.

VSDX and the experimental VSD writer retain nested connector placement. Supported VSDX edits patch local geometry; moving a whole group leaves an unchanged local connector element and its unknown content intact. Source master instances keep unedited descendants implicit. Ungrouped master members materialize supported cached content, with tombstones preventing their old slots from reappearing. Their source definitions remain preserved. Complete inherited formula/action semantics are still missing.

Geometry cache synchronization prevents inherited local values from overwriting the physical frame during materialization and keeps private metadata consistent with exported coordinates. Numeric cache values within tolerance retain their original spelling, and literal Shape Data such as `00125` is preserved. Clipboard and fresh-export IDs wrap within the unsigned 32-bit range; numeric formula references remap across instances without changing quoted literals.

The 23 new tests exercise these behaviors, native event-method resize/Undo, public reopen without private metadata and independent binary parsing. The binary test compares a transformed nested route's world bounds against the independent libvisio conversion, without MacVisio metadata. It does not prove Microsoft Visio acceptance or full pixel equivalence.

Visual QA found reflected text glyphs in flipped groups. Geometry and text now use separate transforms: the text block's placement reflects, while its glyphs retain their handedness. Text-box rotations account for reflection parity. This behavior is corroborated by libvisio's `_flushText` and `transformAngle` implementation in `build/third-party/libvisio/src/lib/VSDContentCollector.cpp`; it remains unverified in Windows Visio. A focused raster test checks identical glyph pixels before/after a plain text shape's horizontal flip, with separate block-position and SVG-transform checks.

Nonuniform scaling of rotated member shapes can require shear that the native node model does not represent. Full one-dimensional ShapeSheet, exact glue ports, curve/routing recalculation, stacking order, line jumps and multiple-edge selection remain incomplete. Windows differential testing and manual native UI testing remain outstanding. Older native archives hydrate missing connector parents from source XML/bindings; source bytes are retained.
